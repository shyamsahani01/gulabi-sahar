# v0.9.0 actual-engine review

These captures are rendered by Godot from the playable scene, not concept images. Regenerate with `./play.sh --fixed-fps 60 --script res://tests/design_review_v09.gd` (requires a display; xvfb can fall back to slow software rendering).

01: gameplay / compact radar; 02: atlas Services tab; 03: drivable vehicle; 04–09: showroom, hospital, police, theka, kirana and chai shop. A successful render is not visual approval. Service buildings are fictional, with walkable interiors and static props; full business/police mechanics are not implemented.

Reference direction: [Kimi 3D workflow](https://www.kimi.ai/academy/3d-tutorial), [Jaipur market streets](https://www.hawa-mahal.com/jaipur-markets/). All new geometry is original code-authored work. The older character likeness defect remains open.
